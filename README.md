# Mystery Island Adventure 🏝️

Mystery Island Adventure is a terminal-based Python game where players explore an island, battle enemies, manage their energy, and work towards finding the treasure.

## Features

- Explore three locations: Forest, Cave, and Temple.
- Battle different enemies.
- Choose between three weapons.
- Manage player energy.
- Rest to recover energy.
- View your inventory.
- Save and continue your progress.
- Start a new game or quit at any time.
- Win by defeating all three enemies.

## Technologies Used

- Python 3
- JSON for saving and loading game progress
- Git and GitHub for version control

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/emmanuellauloko240/Mystery-Island-Adventure.git
   ```

2. Navigate into the project folder:

   ```bash
   cd Mystery-Island-Adventure
   ```

3. Run the game:

   ```bash
   python3 game.py
   ```

## How to Play

1. Choose whether to continue a saved game or start a new one.
2. Select a destination.
3. Choose your weapon when you encounter an enemy.
4. Manage your energy carefully.
5. Defeat all enemies to find the treasure and win!

## Project Goal

The goal of this project was to practise Python programming concepts, including functions, dictionaries, loops, conditional statements, file handling, and JSON data storage.
